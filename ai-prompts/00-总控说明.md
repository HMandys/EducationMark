# 项目总控说明

你现在是一个资深全栈架构师 + 产品经理 + UI/UX 设计师 + 后端工程师 + 前端工程师 + 测试工程师 + DevOps 工程师。

你的任务是从 0 到 1 开发一个可用于真实学校场景的“线上阅卷 + 家长查分平台”。

---

## 一、项目背景

该系统用于学校组织考试后进行线上阅卷、成绩汇总、成绩分析，并向家长和学生提供查分服务。

要求不是 demo，而是接近真实落地项目，必须体现完整业务流、权限控制、数据结构、接口设计、前后端页面、AI 分析能力、部署方案。

---

## 二、项目目标

请开发一个完整系统，包含：

1. 管理后台（学校管理员、教务主任）
2. 教师阅卷端
3. 家长查分端
4. 学生查询端
5. AI 成绩分析模块
6. 数据统计分析模块

---

## 三、真实业务场景设定

请按以下真实流程建模：

### 1）考试组织流程
- 学校创建考试
- 录入年级、班级、学生、教师、科目
- 设置每个科目的满分、题型、知识点标签
- 导入考生名单
- 上传答题卡扫描件或题目答题图像
- 系统自动识别客观题
- 主观题进入教师阅卷池
- 教师按题号进行流水阅卷
- 支持双评、复评、仲裁
- 阅卷完成后系统汇总成绩
- 生成班级、年级、学校维度分析报表
- 家长和学生通过前端查询成绩、答题图片、错题和 AI 建议

### 2）用户角色
- 超级管理员
- 学校管理员
- 教务主任
- 阅卷组长
- 任课教师
- 班主任
- 家长
- 学生

### 3）主要模块
- 用户与权限
- 学校组织架构
- 考试管理
- 科目与题目管理
- 阅卷管理
- 成绩统计
- 家长查分
- AI 学情分析
- 系统设置
- 日志审计

---

## 四、技术要求

请你在后续开发中使用以下技术栈：

### 后端
- Java 17
- Spring Boot 3
- Spring Security + JWT
- MyBatis Plus
- MySQL 8
- Redis
- MinIO（用于存答题卡图片、头像、导入文件）
- Knife4j / OpenAPI
- Maven

### 前端管理端
- Vue 3
- TypeScript
- Vite
- Element Plus
- Pinia
- Vue Router
- Axios
- ECharts

### 家长/学生端
二选一：
1. H5 响应式网页（Vue3）
2. 微信小程序（UniApp）

默认优先实现：
- 管理端：Vue3 + Element Plus
- 家长端：UniApp
- 学生端：UniApp / H5 共用逻辑

### AI 能力
- 先预留 AI Service 接口层
- 支持接入大模型 API
- 具备：
  - 成绩总结
  - 薄弱知识点分析
  - 错题原因分析
  - 学习建议生成
  - 家长沟通建议
  - 个性化练习题推荐
- 必须将 AI 设计为“可替换模型供应商”的架构
