# 后端项目搭建提示词

请你作为资深 Java 后端工程师，为“EduMark 智能阅卷与家长查分平台”生成完整后端项目骨架。

技术栈固定：
- Java 17
- Spring Boot 3
- Spring Security
- JWT
- MyBatis Plus
- MySQL
- Redis
- MinIO
- Maven
- Lombok
- Knife4j

要求：
- 生成真实可运行代码
- 给出完整目录结构
- 不要只给片段
- 代码风格规范统一

请输出：

## 1. Maven 多模块或单模块方案
请先给出推荐项目结构，并解释原因。

建议包含：
- edumark-server
- common
- auth
- system
- exam
- marking
- score
- ai
- file

如果你认为单体模块化更好，也可以改，但必须解释清楚。

## 2. 项目目录结构
输出完整目录树。

## 3. pom.xml
输出：
- 父 pom
- 子模块 pom（如有）
- 所有关键依赖

## 4. application.yml
请提供开发环境配置示例：
- mysql
- redis
- minio
- jwt
- logging
- mybatis-plus

## 5. 基础设施代码
请完整输出以下基础代码：
- 统一返回结果类 Result
- 错误码枚举
- 全局异常处理器
- JWT 工具类
- Spring Security 配置
- 登录认证过滤器
- MyBatis Plus 配置
- Redis 配置
- MinIO 配置
- Knife4j 配置
- 通用 BaseEntity
- 分页对象
- 审计字段自动填充

## 6. 登录模块
请先完成登录认证功能，支持：
- 账号密码登录
- 角色信息返回
- JWT 签发
- 当前用户信息查询
- 退出登录（前端删除 token 即可，后端可做黑名单扩展）

## 7. 权限模型
请实现：
- 用户表
- 角色表
- 用户角色关联
- 权限注解或接口权限控制
- 菜单权限字段预留

## 8. 代码输出要求
请一次性尽量多给完整文件：
- Controller
- Service
- ServiceImpl
- Mapper
- Mapper.xml（如需要）
- Entity
- DTO
- VO
- Config
- Utils

不要偷懒省略关键代码。
