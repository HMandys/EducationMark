# 家长端与学生端提示词

请你为“EduMark 智能阅卷与家长查分平台”开发家长端与学生端。

技术栈：
- UniApp
- Vue3 语法风格
- 可兼容 H5 / 小程序

要求：
- 真实可运行代码
- UI 简洁现代
- 教育产品风格
- 页面逻辑完整

请实现以下功能：

## 一、登录与绑定
### 家长端
- 手机号登录 / 验证码登录（可先做模拟）
- 输入学生姓名 + 学号 + 绑定码进行绑定
- 一个家长可绑定多个学生
- 切换查看不同孩子

### 学生端
- 学号/账号登录
- 查看个人考试列表

## 二、首页
### 家长端首页
展示：
- 已绑定学生卡片
- 最近考试成绩
- 待查看报告
- AI 学习建议摘要

### 学生端首页
展示：
- 最近考试
- 成绩趋势
- 薄弱知识点
- 错题提醒

## 三、成绩查询
支持：
- 考试列表
- 单次考试详情
- 各科成绩
- 总分
- 班级排名/年级排名
- 与上次考试对比
- 是否进步/退步

## 四、答题卡查看
支持：
- 查看各科答题卡图片
- 查看每题得分
- 主观题批注预留
- 错题高亮

## 五、AI 分析页
请设计并实现以下内容：
- 本次考试整体表现总结
- 薄弱知识点分析
- 错误原因归纳
- 学习建议
- 家长辅导建议
- 推荐练习方向

## 六、页面清单
请至少实现：
- 登录页
- 绑定页
- 首页
- 考试列表页
- 考试详情页
- 答题卡页
- AI 报告页
- 我的页面

## 七、接口对接
请给出：
- API 封装
- 页面代码
- mock 数据
- 关键交互逻辑

要求代码完整，不要偷懒。
