# AI 分析模块提示词

请你为“EduMark 智能阅卷与家长查分平台”设计并实现 AI 分析模块。

要求：
- AI 模块必须是可替换模型供应商的架构
- 即使暂时不用真实大模型，也要先写好接口层和 prompt 构造层
- 支持后续接 OpenAI / Claude / 通义 / DeepSeek 等模型

请输出：

## 一、AI 模块职责
实现以下能力：
1. 学生单次考试总结
2. 多次考试趋势分析
3. 知识点薄弱项识别
4. 错题原因归纳
5. 家长沟通建议
6. 个性化练习方向建议
7. 班级整体学情报告

## 二、AI 服务架构
请设计：
- ai-provider 接口
- 不同模型供应商适配层
- prompt builder
- response parser
- fallback 机制
- 分析任务异步化设计

## 三、输入数据模型
请设计 AI 所需输入：
- 学生基础信息（可脱敏）
- 考试信息
- 各科成绩
- 各题得分
- 知识点得分率
- 历次考试趋势
- 班级平均对比
- 错题样本

## 四、输出格式
请统一输出 JSON 结构，包含：
- summary
- strengths
- weaknesses
- causes
- suggestions
- parentAdvice
- practiceFocus

## 五、风险控制
请设计约束：
- 不输出绝对化评价
- 不输出羞辱性措辞
- 不对学生贴标签
- 强调建议仅供参考
- 避免医学、心理诊断式结论

## 六、代码实现
请基于 Spring Boot 写出：
- AIProvider 接口
- MockProvider 实现
- PromptBuilder
- AIAnalysisService
- AIAnalysisTask 调度逻辑
- Controller 接口
- 实体类、DTO、VO

## 七、Prompt 设计
请写出：
- 学生报告 prompt 模板
- 家长建议 prompt 模板
- 班级报告 prompt 模板

要求 prompt 专业、克制、适合教育场景。

## 八、页面展示
请补充前端 AI 报告展示页代码：
- 管理端查看学生 AI 报告
- 家长端查看 AI 建议
- 图文卡片式展示

输出必须尽量完整。
