# UI 设计提示词

请你作为资深产品设计师 + UI 设计师，为“EduMark 智能阅卷与家长查分平台”设计完整 UI 方案。

要求：
- 风格现代
- 教育科技感
- 简洁专业
- 适合学校、教师、家长使用
- 不是花哨炫技风

请输出以下内容：

## 一、整体设计风格
- 主色
- 辅助色
- 功能色
- 背景色
- 卡片风格
- 阴影
- 圆角
- 字体层级
- 图标风格

## 二、端别区分
请分别设计：
- 管理端后台风格
- 教师阅卷端风格
- 家长端风格
- 学生端风格

## 三、关键页面原型说明
请详细描述以下页面布局：
- 登录页
- 管理端仪表盘
- 考试管理页
- 阅卷工作台
- 成绩分析页
- 家长端首页
- 家长端成绩详情
- AI 报告页

## 四、组件规范
请说明：
- 表格
- 表单
- 搜索栏
- 弹窗
- Tabs
- 步骤条
- 数据卡片
- 图表区域
- 图片预览
- 空状态
- 加载状态

## 五、交互规范
请说明：
- 按钮优先级
- 表单校验提示
- 成功/失败提示
- 危险操作确认
- 大表格操作体验
- 移动端交互手势

## 六、请补充
- 每个端的页面文案风格
- 是否适合深色模式
- 响应式建议

最后请输出一套可供前端直接实现的设计规范文档。
