# 接口文档提示词

请你作为后端接口设计师，为“EduMark 智能阅卷与家长查分平台”输出完整 RESTful API 文档。

要求：
- 按模块分类
- 参数清晰
- 返回示例完整
- 贴合前面设计的数据结构

请输出以下模块的 API：

## 1. 认证模块
- 登录
- 获取当前用户
- 刷新 token（可选）

## 2. 用户与权限模块
- 用户列表
- 新增用户
- 编辑用户
- 删除用户
- 分配角色

## 3. 学校组织模块
- 学校管理
- 年级管理
- 班级管理
- 教师管理
- 学生管理
- 家长绑定管理

## 4. 考试管理模块
- 考试 CRUD
- 科目配置
- 题目配置
- 状态流转

## 5. 答题卡模块
- 上传答题卡
- 查询答题卡
- 查看图片

## 6. 阅卷模块
- 生成任务
- 查询任务
- 教师领取任务
- 提交评分
- 仲裁评分

## 7. 成绩模块
- 成绩汇总
- 学生成绩详情
- 班级统计
- 年级统计
- 发布成绩

## 8. 家长端模块
- 家长登录
- 绑定学生
- 查询考试列表
- 查询考试详情
- 查询答题卡
- 查询 AI 报告

## 9. AI 模块
- 创建分析任务
- 查询学生报告
- 查询班级报告

每个接口都要给：
- 请求方式
- URL
- 请求参数
- 响应参数
- 示例 JSON
- 权限要求
